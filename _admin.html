Правки становятся видны на сайте только после нажатия кнопки «Сохранить» в правом верхнем углу (или Ctrl+S) — до этого спокойно правьте текст, ничего никуда не уходит. Можно редактировать одновременно с другого устройства: разные карточки не мешают друг другу, сервер сам сливает правки.

Заявки с формы

Дополнительные получатели — Telegram user ID через запятую
Заявки с формы сайта рассылает Telegram-бот. Каждый получатель должен один раз написать боту /start, иначе Telegram не даст боту прислать сообщение. Свой user ID можно узнать у бота @userinfobot. Токен бота задаётся не здесь, а в настройках хостинга: Railway → Variables → TG_BOT_TOKEN. Основной получатель заявок зашит в код сервера. Чтобы новые ID заработали для всех посетителей — вкладка «Экспорт» и обновление data.js, как с остальным контентом.

Экспорт / импорт

Данные уже хранятся на сервере и видны всем посетителям — экспорт/импорт нужен только для резервной копии или переноса данных. «Скопировать JSON» — сохранить бэкап себе на компьютер. «Импортировать» — заменить текущие данные сайта содержимым поля ниже (сразу сохранится на сервере). «Сбросить к исходным» — вернуть заводские данные из кода сайта.
